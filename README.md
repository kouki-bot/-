# くらしのナビ（初期プロトタイプ）

## ファイル
- `index.html`：ページ構成
- `style.css`：デザイン
- `script.js`：言語切替・タップ式ガイド

## ローカルで確認
`index.html` をブラウザで開いてください。インターネット接続があるとGoogle Fontsが読み込まれます。フォントが読み込めない場合も表示は可能です。

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成（例：`kurashi-navi`）
2. このフォルダ内の `index.html` `style.css` `script.js` をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → `main` / `root` を選択して保存
4. 表示されたURLで確認

## 現在の実装範囲
- スマホ対応のベージュ系トップページ
- 日本語・英語・簡体字中国語・ベトナム語・韓国語の画面切替
- 住まい（退去費用）・買い物（返品）・仕事（退職）のタップ式ガイド
- 公的機関の情報へのリンク
