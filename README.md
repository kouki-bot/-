# くらしのナビ（初期プロトタイプ）

## ファイル
- `index.html`：ページ構成
- `style.css`：デザイン
- `script.js`：言語切替・タップ式ガイド

## ローカルで確認
`index.html` をブラウザで開いてください。インターネット接続があるとGoogle Fontsが読み込まれます。フォントが読み込めない場合も表示は可能です。

## GitHub Pagesで公開
1. GitHubで新しいリポジトリを作成（例：`kurashi-navi`）
2. このフォルダ内の `index.html` `style.css` `script.js` をリポジトリ直下にアップロード
3. Settings → Pages → Deploy from a branch → `main` / `root` を選択して保存
4. 表示されたURLで確認

## 現在の実装範囲
- スマホ対応のベージュ系トップページ
- 日本語・英語・簡体字中国語・ベトナム語・韓国語の画面切替
- 住まい（退去費用）・買い物（返品）・仕事（退職）のタップ式ガイド
- 公的機関の情報へのリンク

## 公開前の注意
これは動作確認用の試作版です。翻訳・制度説明・リンク先は公開前に必ず確認してください。現在、他のカテゴリーは「準備中」です。お気に入り、アカウント、期限通知、決済はまだ実装していません。法的判断を代替するものではありません。

## v2への更新方法

GitHubリポジトリ直下の `index.html` と `script.js` を、このZIP内の同名ファイルで置き換えてコミットしてください。`style.css` は変更していないため、そのままで構いません。
