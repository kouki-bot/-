# くらしのナビ

「困ったとき、選ぶだけで解決方法が見つかる。」を目指す、生活トラブル・手続き案内の静的Webサイトです。

## ファイル
- `index.html`：ページ構成・10テーマの入口
- `style.css`：デザイン
- `script.js`：言語切替、質問分岐、結果表示

## 現在の実装
- スマートフォン対応のベージュ系トップページ
- 日本語・英語・簡体字中国語・ベトナム語・韓国語の表示切替
- 6カテゴリーから代表テーマへ移動
- 12テーマのタップ式ガイド
  1. 退去費用が高すぎると感じる
  2. 通販で返品したい
  3. 仕事を辞めたい
  4. 家賃の値上げを求められた
  5. 近隣の騒音に困っている
  6. 身に覚えのない請求がある
  7. 解約後も請求が続いている
  8. 失業給付を知りたい
  9. 引っ越し後の住所変更をしたい
  10. 賃貸住宅で水漏れが起きた
- 回答内容に応じた優先アクションと共通案内の表示
- 公的機関・相談窓口へのリンク

## ローカルで確認
`index.html` をブラウザで開いてください。インターネット接続があるとGoogle Fontsが読み込まれます。フォントが読み込めない場合も基本表示は可能です。

## GitHub Pages
GitHub Pagesの設定で、公開元ブランチとフォルダを指定してください。現在の公開URLはリポジトリのPages設定で確認できます。
